# Fonts

Self-hosted so the site makes no third-party requests. Both faces are licensed
under the SIL Open Font License 1.1, which permits redistribution.

    ibm-plex-mono-400.woff2   IBM Plex Mono, regular   — structure, labels, code
    ibm-plex-mono-500.woff2   IBM Plex Mono, medium    — skill names, emphasis
    newsreader-var.woff2      Newsreader, variable     — questions and prose
                              one file, weights 400-600

Latin subset only. Newsreader is a single variable file declared with a
`font-weight: 400 600` range, so both weights cost one download.

Licences: `OFL-IBMPlexMono.txt`, `OFL-Newsreader.txt`.
Sources: <https://github.com/IBM/plex>, <https://github.com/productiontype/Newsreader>
